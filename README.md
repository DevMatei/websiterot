# coderot (website edition)

inspired by the coderot trend on tiktok (which in all fairness, is now dead), this project "rots" the website until its gone :0

project made for [Hackclub's Hacklet](https://hacklet.hackclub.com/)

No AI was used in the making of this project.

I am trying to make the code well documented and readable hence the "spam" of comments in it

# install

1. show your bookmarks bar (ctrl+shift+b or cmd+shift+b on mac)
2. right click and select `add page` or `add bookmark` depending on your browser
3. name it `coderot` or anything else, it dosent really matter
4. paste this as the url:
